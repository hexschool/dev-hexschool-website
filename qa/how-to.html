邁向前端工程師 / 設計師之路

不知道該如何規劃嗎？

你可以依據過去的背景以及將來的目標來選擇，整個網頁開發前端我們給予了基本的兩大方向，

從第 1 關開始

兩個終點，選一個

第 1～5 關網頁設計師適合具有設計背景，或經過美感訓練者投入第 1～10 關＋2 條支線前端工程師所有人皆可投入，學習時間長，但發展更好的職位

學習路線

  1. 萬丈高樓平地起，前端設計的基礎課程。

    • 六角課程使用 HTML、CSS開發一個網站
    書籍推薦
    • HTML&CSS：網站設計建置優化之道

  2. 網站互動性的基礎課程，也是邁向 JavaScript 的前哨站。

    • 六角課程使用 jQuery 打造互動性網頁效果
    書籍推薦
    • 深入淺出 jQuery

  3. 練習練習再練習，強化 HTML、CSS、jQuery 的基礎觀念。

    觀念補充

    完成 codecademy 的題目

    • HTML & CSS
    • jQuery
    *網站架設
    • 將網頁上傳到 Github Pages，讓你的網站能夠透過網址讓其他人看到
    繼續練習
    • 下載 速記表自己找五個 jQuery Plugin 套用在網頁上

  4. 行動網站使用率已超過 7 成，這已經是前端開發中的必備技能。

    • 六角課程一變應萬變的響應式網頁設計
    作業練習
    • 將 RWD 課程設計稿製作成 RWD 版型

  5. 不論手刻派、框架派都應該要了解的 SASS/SCSS 開發，學習打造易維護、好管理的 CSS 架構。

    • 六角課程Sass 實戰全攻略 (影音課程)
    作業練習
    • 甜點電商 （使用 Bootstrap 結合 Sass 製作版型 - 甜點電商）

  6. Bootstrap 是 CSS 的框架，熟悉此技能可以加快開發速度，並且增加 CSS 的可用性

    • 六角課程Bootstrap 5 網頁切版整合術
    中文文件
    • Bootstrap 繁體中文手冊
    作品參考
    • 麵屋
    • 與森對話
    • Booky
