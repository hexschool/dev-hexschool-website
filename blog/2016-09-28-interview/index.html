有志竟成 陳景安：「面對的態度最重要，起步永遠不嫌晚。」

沒有前端背景的景安，對前端的熱愛始於大學四年級的選修課，經歷5-6年的自學撞牆期，這份熱忱絲毫沒有減退。2016年，偶然發現了「六角學院」，在年資與年紀都有一定的條件下，毅然決然地辭掉網路行銷企劃的工作，她知道自己起步晚因此更加全心全意投入學習。現在，她在資訊公司擔任前端工程師，她愛這份工作！

Q：為何對前端產生了興趣？

景安：在大學四年級的選修課 -- 「網頁製作」，是使用 Adobe Dreamweaver 簡單排版，當時覺得很有趣！

一直到出社會後無名小站興起，大家開始流行製作自己專屬的 CSS 部落格主題，第一次看到密密麻麻的程式碼，發現原來是這些東西在控制著網頁的樣式，而非只是 Adobe Dreamweaver 點選的方式製作，這才開始有想進一步學習程式碼，不過因為是非本科系的，在自學的時候總是在撞牆期徘徊，並且無法有系統的學習也相當困擾，這樣的情況持續了5-6年，但也都沒有想過要放棄，一直在尋找學習方法與管道。(無奈)

Q：學習前端技術有很多原因，像景安就是為了「轉職」，在過程中老師有給你甚麼樣的建議嗎？

景安：早期104人力銀行並沒有前端工程師這樣的職位，只要是寫 coding 的都屬工程師並沒有前、後端之分，所以我也不知道該怎麼去學這領域的東西。

沒有基礎、概念，甚至無從得知未來若要從事相關工作，到底需要具備甚麼條件，在這樣的情況下，只能一邊摸索一邊從事其他工作。

我把前端想得很難，難到我一直在懷疑自己是否夠格應徵，不過洧杰老師分析了這份徵才內容，評估我現階段的程度，他認為沒有問題，相信我可以勝任！(笑)

給了我許多建議與方向，讓我補足我欠缺的技能。

Q：關於前端，妳都是如何摸索自學的呢？

景安：通常會先筆記技術的名稱 → 搜尋資料 → 了解基本觀念、使用方式 → 搜尋範例 → 開始實作。

當時都是利用下班後的時間自學，也有想過要去巨X、X成上課，但礙於價格與周遭朋友的上課經驗，心裡還是有些怕怕的！

也有參加大學推出的社區課程，學習 HTML 、 CSS 基礎，收費落在10,000元以下，還在能接受的範圍內，就這樣一邊做著行政工作一邊學習，想要把自己的基礎觀念架起來。

Q：為什麼之後選擇六角學院呢？

景安：其實覺得自己年紀也不小了，即便與行政工作無關，還是一直持續學習前端技術，但對於轉職也只是念了好久一直沒有行動，因為覺得自己的程度還不夠，

參加六角學院 HTML、CSS 課程的一個月後，我發現這課程值得好好學習，真的覺得可以從這裡開始奠定轉職基礎，因此下定決心！

因為不是本科系出生，身邊無具相關知識的朋友，遇到問題也沒有老師可以發問，六角學院 提供了可以隨時隨地發問的平台，覺得很佛心。

Q：與其他你參加過的社區課程相比，六角學院 有甚麼差異之處呢？

景安：即便參加了專業課程，心裡還是覺得沒有系統，一般實體課程都屬一次性，這堂課忘了就忘了，無法回播；

有些課程的老師因授課時間的限制，無法一一釐清問題，許多細節也只是帶過，導覽式的簡單介紹工具的名稱與使用方式，很難與實際應用做結合；

然而線上課程的優勢在於"能不斷重複地複習"，邊學邊做若遇到問題能夠反覆驗證，正是我喜歡的學習模式，老師的講解方式也很適合我，洧杰老師傳授的是循序漸進的觀念，而非制式化的學術性理論，他耐心地說到你懂，也能隨時個別回答同學們問題，因此我覺得六角學院挺適合我的(笑)。

Q：目前公司前端工程師的工作內容？

景安：公司偏向接案，會隨著案子的需求學習不同的新技術，目前手上的案子都還滿上手的(笑)。

Q：若在工作上遇到了問題，你會怎麼做？

景安：我比較偏向自己找尋問題的答案，雖然說有前輩帶著會比較好，但對於日新月異的網路技術產業而言，自主性的開發與學習新技術，是個不可或缺的技能。

Q：當初應徵這個職位，所需具備的條件為何？

景安：前端工程師由於是銜接美術與後端的橋樑，我認為需要具備溝通技巧、有耐心、能把話說精準的人格特質。

Q：在面試的時候，有甚麼令你印象最深刻的嗎？

景安：在面試前，洧杰老師有替我模擬面試，令人驚訝的是老師模擬的面試方向與題目都相當的準確，

印象最深刻的就是「對未來的進修規劃」、「有無想要增進自己的那些技能？」，這類型的題目很能展現自己的想法與個人特質。

Q：六角學院希望能夠塑造更多像你這樣優秀的學員，最後可以給學弟妹一些建言嗎？

景安：遇到不熟悉的事物時，面對的態度是最重要的！勇敢嘗試，起步永遠不嫌晚。
