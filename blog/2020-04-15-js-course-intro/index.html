JavaScript 組合包介紹

我們是六角學院，到了現在已經培育出許多網頁開發者並成功進入業界，「JavaScript 組合」特別推薦給想深入了解 JS 觀念與應用的開發者。

誰適合這組合？

  • 具有基礎的網頁開發經驗的網頁設計師
  • 預期更深入學習前端開發的工程師
  • 有接觸過 jQuery，但對於 JS 尚不熟悉者
  • 想要累積作品，但前端技術掌握尚不熟悉者

如果你對於自己的 JavaScript 能力還不是很清楚，可以參考以下考題：

  • 基礎 JS 試題：標準為 90 分
  • 核心 JS 試題：總題數 40，標準為 35 題正確

這組合使用什麼工具？

本課程皆是使用 VSCode 進行開發，講義及範例也都附在課程內，不需要額外購買。

這組合合適的職缺？

  • 前端設計師
  • 前端工程師

這組合課程如何做學習？

組合包內包含不同的課程內容，「JavaScript 組合包」包含以下課程：

  • JavaScript 前端修練全攻略
  • JavaScript - 核心篇
  • Vue 3 實戰影音課程

為了確保學習狀況，每個課程皆有多個章節及作業，請遵循課程內容，完成各章節作業，並且課程最後都有最終作業，完成這些最終作業將具有求職的最佳作品！

學習的過程中一定會遇到許多的問題，課程平台下方均有問答工具：

  • 我們助教都非常熱心，請盡可能地提出你的問題，助教將會盡快回覆你的問題！
  • 章節或最終作業如果遇到問題，你的問題或許其他人也有遇過，可在問答區中尋找其它同學的開發過程，挑戰並完成它吧。

補充：六角學院具有強大的助教系統，至今已經具有超過萬筆的問答紀錄，每日都有二三十份新的問題提出，所以請別吝嗇提出你的問題～

這組合課程可以學到什麼程度

本組合包含多個課程，依序可掌握以下技能：

  • 基礎 JavaScript 觀念
  • JavaScript 對於 DOM 的操作
  • AJAX 行為
  • 掌握所有 JavaScript 核心觀念（This、原型鍊、建構式、閉包、常用 ES6 語法等）
  • 學習並掌握 Vue 框架
  • 使用 Vue 框架完成電子商務類型的網站

接下來還可以投入哪個方向？

  • 投入不同的 JavaScript 框架運用，增加職場競爭力
  • 學習 Node.js，掌握前後端開發技能
  • 學習 UI ，培養美感設計出具有價值的網頁

報名這組合課程，包含哪些服務？

大多線上課程僅有提供教學影音，並無提供完善的助教、講師回覆系統，因此在學習上有任何問題都無從發問，甚至發問後一個月才收到講師簡短的回覆，來回的過程中將浪費許多寶貴時間，且無法真正的掌握技能。

六角學院除了提供影音課程外，完善的學習輔助系統，確保你的每一分投入都發揮最大的效益！

  • 影音課程保證觀看期限一年：六角每多營運一年，你就獲得多一年的觀看期，課程更新也無需另外付費
  • 完善的助教、講師回覆系統，確保學習狀況
  • 免費參加每週的大神來六角或線上問答
  • 完成所有最終作業可免費職缺推薦
