網頁設計組合包介紹

我們是六角學院，到了現在已經培育出許多網頁開發者並成功進入業界，「網頁設計組合」特別推薦給對於網頁開發有興趣的新人。

誰適合這組合？

  • 還沒有開發經驗，但想試著投入的新人
  • 想要轉網頁設計師的平面設計師
  • 有些許經驗，但網頁基礎還不夠熟練的同學

這組合需要什麼設備？

六角學院主要是經營線上課程，相較於其他實體課程來說具有更多的彈性，且在上課程僅需要一台電腦即可開始上課，課程中會提供許多額外的軟體及教材，這些都是免費的，且課程中會介紹該如何運用這些免費工具提高個人的價值。

  • 一台電腦
    • Windows 或 Mac OS 作業系統皆可
    • 可以運行 Chrome 瀏覽器的電腦
    • 可播放影片順暢的網路

本課程使用的軟體皆是免費的，講義及範例也都附在課程內，不需要額外購買。

這組合合適的職缺？

  • 網頁設計師
  • 前端設計師

這組合課程如何做學習？

組合包內包含不同的課程內容，「網頁設計組合包」包含以下課程：

  • 使用 HTML、CSS 開發一個網站
  • jQuery 打造互動性網頁動畫效果
  • 一變應萬變響應式網頁設計 (RWD)
  • Bootstrap 5 網頁切版整合術

為了確保學習狀況，每個課程皆有多個章節及作業，請遵循課程內容，完成各章節作業，並且課程最後都有最終作業，完成這些最終作業將具有求職的最佳作品！

學習的過程中一定會遇到許多的問題，課程平台下方均有問答工具：

  • 我們助教都非常熱心，請盡可能地提出你的問題，助教將會盡快回覆你的問題！
  • 章節或最終作業如果遇到問題，你的問題或許其他人也有遇過，可在問答區中尋找其它同學的開發過程，挑戰並完成它吧。

補充：六角學院具有強大的助教系統，至今已經具有超過萬筆的問答紀錄，每日都有二三十份新的問題提出，所以請別吝嗇提出你的問題～

這組合課程可以學到什麼程度

本組合包含多個課程，依序可掌握以下技能：

  • HTML 及 CSS 的切版能力
  • 開發多頁式的網站
  • 具有開發響應式網頁的能力（RWD）
  • 具有活用 Bootstrap 的開發能力

這組合課程會有什麼成品？

Bootstrap 最終作業

Bootstrap 學員作品：

  • 麵屋
  • 島津燒肉
  • 來點多肉吧

RWD 最終作業

接下來還可以投入哪個方向？

  • 學習 JavaScript 成為專業的前端工程師
  • 學習 UI ，培養美感設計出具有價值的網頁

報名這組合課程，包含哪些服務？

大多線上課程僅有提供教學影音，並無提供完善的助教、講師回覆系統，因此在學習上有任何問題都無從發問，甚至發問後一個月才收到講師簡短的回覆，來回的過程中將浪費許多寶貴時間，且無法真正的掌握技能。

六角學院除了提供影音課程外，完善的學習輔助系統，確保你的每一分投入都發揮最大的效益！

  • 影音課程保證觀看期限一年：六角每多營運一年，你就獲得多一年的觀看期，課程更新也無需另外付費
  • 完善的助教、講師回覆系統，確保學習狀況
  • 不定期免費參加線上研討會 - 大神來六角、線上問答
  • 完成所有最終作業可免費職缺推薦
