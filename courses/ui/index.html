UI 設計與平面設計的大差異

平面設計

介面設計

內容可以被互動操作

平面設計的成品會在輸出物上，當輸出後畫面則不再更動；UI 設計的成品則會出現在電腦及行動裝置上，且會隨著用戶操作不斷的改變，因此如何引導用戶正確操作是介面設計師的重要課題。
